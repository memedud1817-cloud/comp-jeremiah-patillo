JEREMIAH PATILLO - ENGL-110 PORTFOLIO

This folder contains the complete six-page portfolio:
- index.html
- learning-claim.html
- artifact-1.html
- artifact-2.html
- artifact-3.html
- reflection.html
- styles.css

TO OPEN:
1. Extract this ZIP file.
2. Keep all files together in the same folder.
3. Double-click index.html to open the portfolio in your browser.
4. To edit it in VS Code, choose File > Open Folder and select this folder.
5. If you have Live Server installed, right-click index.html and choose Open with Live Server.

The shared styles.css provides the black space background, bright yellow stars,
and white glowing details across all pages.
